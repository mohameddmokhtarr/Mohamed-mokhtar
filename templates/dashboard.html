Setup Guide

Getting Started with Instagram Graph API

Step 1: Convert Your Instagram Account

  1. Open Instagram app → Settings → Account
  2. Select "Switch to Professional Account"
  3. Choose "Business" or "Creator"

Step 2: Create a Facebook Developer App

  1. Go to developers.facebook.com
  2. Click "My Apps" → "Create App"
  3. Choose "Business" type
  4. Fill in app details and create

Step 3: Add Instagram Graph API

  1. In your app dashboard, click "+ Add Product"
  2. Find "Instagram Graph API" and click "Set Up"
  3. Go to Settings → Basic and copy your App ID and App Secret

Step 4: Generate Long-Lived Access Token

  1. Go to Graph API Explorer
  2. Select your app from the dropdown
  3. Click "Generate Access Token"
  4. Select permissions: instagram_business_basic, instagram_manage_comments, instagram_manage_messages
  5. Generate a long-lived token (lasts 60 days)

Step 5: Get Your Business Account ID

  1. In Graph API Explorer, run this query: me/ig_user_id
  2. Copy the id from the response

Step 6: Configure Webhook (Optional)

To receive real-time comment notifications:

  1. In app settings, go to Products → Instagram Graph API → Webhooks
  2. Click "Edit Subscriptions"
  3. Set Callback URL to: https://yourapp.com/webhook/instagram
  4. Set Verify Token to a secure random string
  5. Subscribe to: comments, messages
⚠️ Important Notes:
  • Access tokens expire after 60 days. Generate a new one regularly.
  • DMs require either: (a) user previously messaged the business, or (b) approved instagram_manage_messages permission.
  • Keep your access token secure. Never commit it to version control.
